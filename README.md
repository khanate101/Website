# الفخامة – Al Fakhamah

متجر إلكتروني عربي مبني باستخدام PHP 8.2 وMySQL 8.

> حالة المشروع: تأسيس البنية الأولية. لا يُعد المتجر جاهزاً للإنتاج حتى استكمال مراحل الإدارة والطلبات والاختبارات.

## المتطلبات
- PHP 8.2+
- MySQL 8+
- Composer
- تفعيل PDO وpdo_mysql وfileinfo

## التشغيل
1. انسخ `.env.example` إلى `.env` وأدخل بيانات قاعدة البيانات.
2. أنشئ قاعدة بيانات MySQL ثم استورد `database/schema.sql`.
3. نفّذ `composer install`.
4. اجعل مجلد `public/` هو Document Root في الاستضافة.
5. افتح الموقع عبر HTTPS.

راجع هذا الملف بعد اكتمال مراحل المشروع للحصول على دليل التثبيت النهائي.
